1. Connect Claude / ChatGPT (custom MCP)

In ChatGPT or Claude “Connect to a custom MCP”: URL = MCP URL below. Leave any Bearer token environment-variable field empty. Under Headers, set Authorization to the Copy header value (Bearer <token>). Do not put Device ID in the MCP form.

If ChatGPT says tools are unavailable but Desk still shows Cloud checked in: open the FennSill connector → Refresh (or re-save the Authorization header), then start a new chat. Do not mint a new device key. Last resort: delete the connector and add the same URL + header again.
