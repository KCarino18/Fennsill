Tools exposed by the Fennsill Model Context Protocol server for Claude, ChatGPT, Cursor, Gemini, Grok, and compatible clients. The buyer talks to their AI; the AI calls these tools. Never substitute a web preview for a panel push.

list_panels → push_chart or push_artifact → delivered: true

Core tools

list_panels

Call first Cloud Local

Lists e-ink panels linked to the account (cloud) or plugged in over USB (local). Returns device_id values required by push tools, plus online / setup hints on cloud.

ParameterRequiredNotes
No parameters.

push_chart

Graphs Cloud Local

Preferred path for charts. Pass structured data; the server renders a clean 800×480 black/white page and pushes it. Do not hand-write HTML for simple graphs.

ParameterRequiredNotes
device_id Cloud From list_panels (example FSA1B2C3D4E5F6). Optional on local USB.
title Yes Chart headline on the panel (max 80 characters).
labels Yes Array of category names, 1–24 items.
values Yes Numeric series; must match labels length.
chart_type No auto (default), bar, line, hbar, table.
unit No Optional suffix such as $ or %.
subtitle No Secondary line under the title.

push_artifact

Custom layout Cloud Local

Push a finished custom page for checklists and multi-section dashboards. For simple graphs from data points, use push_chart instead.

ParameterRequiredNotes
device_id Cloud From list_panels.
html or svg One 800×480, pure black/white, inline CSS only, no external URLs. Prefer HTML for dashboards.
title No Optional job label on cloud.

Status & live feeds

get_push_status

Status Cloud Not local

Confirm whether a push reached the panel. Use when delivered is false, or to inspect recent jobs for a device.

ParameterRequiredNotes
job_id One of From the last push_chart / push_artifact response.
device_id One of Lists recent jobs for that panel when job_id is omitted.

start_live_update

Recurring Cloud Local

Start a recurring live feed so the panel stays current without pasting content. Not for one-shot charts — use push_chart for those.

ParameterRequiredNotes
device_id Cloud From list_panels.
kind Yes Currently nfl_scores only.
interval_sec No Default 300. Allowed range 60–3600.
title No Optional feed label.

stop_live_update

Stop feed Cloud Local

Stops a live feed previously started with start_live_update.

ParameterRequiredNotes
device_id Cloud From list_panels.
kind No Omit to stop all live feeds on that panel.

set_wifi

USB only Local Not cloud

Sends home Wi‑Fi credentials to the panel over USB. Intentionally unavailable on cloud MCP.

ParameterRequiredNotes
ssid Yes Network name (max 32 characters).
password Yes Wi‑Fi password (max 63 characters).

Success rule

Only tell the user the screen updated when the tool returns delivered: true. If delivery is pending or failed, report the status or call get_push_status with the job_id.

Example — graph from data
1. list_panels
2. push_chart(
     device_id  = "FSA1B2C3D4E5F6",
     title      = "Q1–Q4 Revenue",
     labels     = ["Q1", "Q2", "Q3", "Q4"],
     values     = [12, 18, 15, 22],
     chart_type = "auto",
     unit       = "$"
   )
3. Confirm delivered: true
